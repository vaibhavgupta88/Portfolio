# ⚡ Vaibhav Gupta — Software Engineer Portfolio

A modern, high-performance, minimalist personal portfolio crafted with **React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, and Leaflet**.

## 🌟 Highlights

- **Cinematic Entrance**: Full-screen shared `layoutId` morphing intro with Apple quintic easing (`[0.16, 1, 0.3, 1]`) and lens blur transitions.
- **Apple Bento Grid**:
  - **Featured Projects**: Flagship applications ([Rank Pilot](https://seo-rank-tracker-nu.vercel.app/) & JeevanSetu) with live links and direct GitHub repositories.
  - **Noida Map Widget**: Real Leaflet interactive map with custom pulsing beacon and architectural typography.
  - **Education Widget**: JSSATE Noida B.Tech in IT (GPA: 7.91 / 10.0) with bulleted coursework.
  - **Leadership Widget**: Vice-President at JSS Films & TEDx roles.
  - **What I'm Reading**: *As A Man Thinketh* by James Allen with hover color reveal & 3D spine depth lighting.
- **Non-Card Technical Expertise**: 4 clean divided category columns showcasing full-stack MERN, C++ DSA, and Gemini AI toolchains.
- **Frosted Glass UI**: visionOS-inspired glassmorphism (`backdrop-blur-2xl`, specular highlights).
- **Interactive Contact Modal**: Direct inbox message dispatch with live verification and confirmation receipt.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS
- **Animations**: Framer Motion
- **Map Visuals**: Leaflet, CartoDB Positron
- **Icons**: Lucide React

---

## 🚀 Getting Started

### 1. Installation

```bash
cd frontend
npm install
```

### 2. Run Development Server

```bash
npm run dev
```

Visit `http://localhost:5173` to explore the portfolio.

### 3. Production Build

```bash
npm run build
```
